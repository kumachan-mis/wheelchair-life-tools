## リポジトリ共通の原則

ここに記載するのは、個別スキルの手順ではなく、すべてのスキルに共通する設計・運用上の原則です。

- **本人の主体性を尊重する**：AIは判断材料を提供する。本人の意思や実体験に基づく判断を、一般論やAIの推定で上書きしない。
- **個人差を前提にする**：「車いす利用者」などの属性だけから、能力・必要な支援・適切な選択を一律に決めない。
- **事実と推定を区別する**：確認できた事実、推定、未確認事項を混同せず、不確かなことを断定しない。
- **プライバシーを守る**：個人を特定できる情報や、本人の行動・生活に関する情報を必要以上に収集・公開しない。公開リポジトリには個人固有のデータを含めない。
- **外部の権利・規約を尊重する**：外部サービスの規約、著作権、データの利用条件を確認し、それらに反する取得・保存・再配布を行わない。

## 使い方

各スキルの `SKILL.md` に記載された導入・設定方法に従ってください。スキル固有の前提条件や利用者別の設定がある場合は、そのスキルの `references/` などに記載します。
