# 入店レベル基準（利用者ごとの基準）

この分類は一般的なアクセシビリティ等級ではなく、店舗の状態と利用者本人の車いす・移動能力・介助条件をマッチングして判定する。
以下の数値や介助人数は目安であり、本人の実地判断を優先する。同じ店舗でも利用者によってレベルや利用可否が異なり得るため、AIが別の利用者にそのまま適用してはならない。

| 判定 | 定義 |
|---|---|
| レベル0 | 本人が介助なしで入店経路を通過できる |
| レベル1 | 介助者1人が必要。小さな1段の段差など。前後を順番に持ち上げる、または押し上げることで対応できる |
| レベル2 | 介助者2人が必要。大きな1段の段差など。車いすを短い距離、完全に持ち上げる必要がある |
| レベル3 | 介助者3人が必要。複数段の階段など。比較的長い距離、車いすを完全に持ち上げ続ける必要がある |
| 不可 | 入口幅が足りず車いすが通れない、エレベーターのない長い階段など、物理的・安全上通行できない |

## レベル判定の考え方

レベルは、本人がその店舗を利用するために必要な介助の程度を、店舗の状態と本人の状態を照合して表す。段差・入口幅などの入店経路だけでなく、着席方法や乗り移りが本人にとって利用の障壁になる場合は、その条件も判定に反映する。

店舗側の観察事実（例：小さな段差、座敷中心、入口が狭い、什器移動が必要）と、本人側の条件（例：段差を越える能力、車いすの重量・幅、乗り移りの可否、介助条件）は分けて記録する。そのうえで両者をマッチングし、本人にとってのレベルと今回の利用可否を判断する。

したがって、乗り移りや座敷利用を一律にレベルから除外してはならない。一方、本人が問題なく実行できる動作を理由に、機械的にレベルを引き上げる必要もない。

## 補足

- 分類の中心は、入店経路を通過するために積極的に車いすを持ち上げる介助者の人数。
- ドアは店員に開けてもらえるため、通常は主要な障壁ではない。ただし開口後の有効幅は重要。
- 段差の高さは目安として、約5cmならレベル0または1、約10cmならレベル2相当になり得る。ただし固定ルールではなく、実際の形状・進入角度・車いす・介助方法で変わる。
- 1段か複数段かだけでは判定できない。段差が1段でも大きければ複数人の介助が必要になり得る。
- 入口幅が足りない場合は、段差を越えられるかに関係なく「不可」。
- 一般的な「車いす可」「ベビーカー可」は、個々の利用者のレベルを直接意味しない。
- 大人数がいる特別な状況では通常なら不可の店に一時的に入れる可能性がある。ただし、本人が自分で選ぶ店の通常判定とは分ける。
- AIは最終判断者ではない。利用者本人の実地判断を正解として扱う。

## 店舗側の条件と本人側の条件

次の項目は確認観点の例であり、固定の質問票ではない。今回の店舗の判定に関係する項目を選び、分かる範囲で具体的に記録する。情報がなければ推測で埋めず「未確認」とする。

- **店舗側の条件**：段差・通路・入口幅・着席方法・座敷・障害物・什器移動・店員の協力・店舗側の運用など。
- **本人側の条件**：車いすの重量・幅・形状、段差への対応、乗り移りの可否や必要な介助、利用できる介助者など。
- **条件の組み合わせ**：それぞれを別々に記録したうえで、本人にとってどの条件が障壁になるかを照合する。本人情報が不足している場合は、判定に必要な点だけを確認する。

## 外食条件に応じた可否判定

レベルは店舗の状態と本人の状態をマッチングした結果として判定する。実際に今回行けるかは、同行者の総人数ではなく、必要な介助を実行できる人数・条件と照合する。着席・乗り移り等も本人にとって実行可能か確認し、必要に応じてレベルや利用可否に反映する。

| 店舗レベル | 目安となる介助者 | 介助者1人での外食 |
|---|---:|---|
| レベル0 | 0人 | 可 |
| レベル1 | 1人 | 可（介助可能な同行者がいる場合） |
| レベル2 | 2人 | 不可 |
| レベル3 | 3人 | 不可 |
| 不可 | 人数に関係なく通行不能等 | 不可 |

ただし、段差の寸法・形状、本人の対応能力、介助者の対応可否など、結論を左右する情報が分からない場合は「要確認」とする。同行者がいることと、その人が車いすを持ち上げられることは同義ではない。店舗条件と本人条件の組み合わせによって、同じ店舗でも判定は異なる。
