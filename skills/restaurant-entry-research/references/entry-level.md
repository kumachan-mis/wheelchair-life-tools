# 入店レベル基準（利用者ごとの基準）

この分類は一般的なアクセシビリティ等級ではなく、利用者本人の車いす・移動能力・介助条件に合わせて設定する。
以下の数値や介助人数は目安であり、本人の実地判断を優先する。AIが別の利用者にそのまま適用してはならない。

| 判定 | 定義 |
|---|---|
| レベル0 | 本人が介助なしで入店経路を通過できる |
| レベル1 | 介助者1人が必要。小さな1段の段差など。前後を順番に持ち上げる、または押し上げることで対応できる |
| レベル2 | 介助者2人が必要。大きな1段の段差など。車いすを短い距離、完全に持ち上げる必要がある |
| レベル3 | 介助者3人が必要。複数段の階段など。比較的長い距離、車いすを完全に持ち上げ続ける必要がある |
| 不可 | 入口幅が足りず車いすが通れない、エレベーターのない長い階段など、物理的・安全上通行できない |

## レベル判定の範囲

レベルは、本人の車いすで入口から店内の利用可能な場所まで移動する際に必要な介助の目安を表す。**着席・飲食の方法や店舗側の受け入れ条件を、入店レベルに混ぜない。**

例えば、入口で車いすから椅子へ乗り移る必要があっても、本人が自力で乗り移れて入店経路にも介助が不要なら、入店レベルは0とし、利用条件に「車いすから座席への乗り移りが必要」と記録する。座敷中心の店舗も同様に、座敷への乗り移りの可否を別に扱う。

## 補足

- 分類の中心は、入店経路を通過するために積極的に車いすを持ち上げる介助者の人数。
- ドアは店員に開けてもらえるため、通常は主要な障壁ではない。ただし開口後の有効幅は重要。
- 段差の高さは目安として、約5cmならレベル0または1、約10cmならレベル2相当になり得る。ただし固定ルールではなく、実際の形状・進入角度・車いす・介助方法で変わる。
- 1段か複数段かだけでは判定できない。段差が1段でも大きければ複数人の介助が必要になり得る。
- 入口幅が足りない場合は、段差を越えられるかに関係なく「不可」。
- 一般的な「車いす可」「ベビーカー可」は、個々の利用者のレベルを直接意味しない。
- 大人数がいる特別な状況では通常なら不可の店に一時的に入れる可能性がある。ただし、本人が自分で選ぶ店の通常判定とは分ける。
- AIは最終判断者ではない。利用者本人の実地判断を正解として扱う。

## 利用条件（レベルとは別に記録）

次の項目を確認し、分かる範囲で具体的に記録する。情報がなければ推測で埋めず「未確認」とする。

- **着席方法**：車いすのまま着席できる／椅子へ乗り移る／座敷へ乗り移る／その他。
- **乗り移り**：本人が自力でできるか、介助が必要か。本人の能力に依存するため、座席形式だけで利用不可と決めない。
- **入口・通路の余裕**：車いすの幅に対して余裕があるか、ぎりぎりか。寸法が不明なら「ぎりぎりに見える」など観察として記載する。
- **障害物・配置**：傘立て、看板、家具、商品などの移動が必要か。通常配置で通れるか、店員の協力後に通れるかを分ける。
- **車いす依存性**：重量・全幅・全長・旋回スペースなどによって通過可否が変わりそうか。
- **店舗側の運用**：入店を断られた等の情報は、物理的に通れないことの証拠とは限らない。物理的障壁、乗り移り条件、店舗側の受け入れ判断・運用を分けて記録する。

## 外食条件に応じた可否判定

レベルは店舗側の物理的な入店難易度を表す。実際に今回行けるかは、同行者の総人数ではなく、持ち上げ介助を実行できる人数・条件と照合する。さらに、着席・乗り移り等の利用条件が本人にとって実行可能かも確認する。

| 店舗レベル | 目安となる介助者 | 介助者1人での外食 |
|---|---:|---|
| レベル0 | 0人 | 可 |
| レベル1 | 1人 | 可（介助可能な同行者がいる場合） |
| レベル2 | 2人 | 不可 |
| レベル3 | 3人 | 不可 |
| 不可 | 人数に関係なく通行不能等 | 不可 |

ただし、段差の寸法・形状や介助者の対応可否が分からない場合は「要確認」とする。同行者がいることと、その人が車いすを持ち上げられることは同義ではない。レベル0でも、乗り移りや什器移動などの条件が本人にとって実行できない場合は、外食全体の判定を「要確認」または「不可」とする。
