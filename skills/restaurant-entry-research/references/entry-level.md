# 入店レベル基準（初期テンプレート）

この分類は一般的なアクセシビリティ等級ではなく、利用者本人の車いす・移動能力・介助条件に合わせて設定するための初期テンプレートである。
以下の数値や介助人数はサンプルであり、利用者本人と確認して調整すること。AIが別の利用者にそのまま適用してはならない。

| 判定 | 定義 |
|---|---|
| レベル0 | 完全に一人で入店できる |
| レベル1 | 介助者1人が必要。小さな1段の段差など。前後を順番に持ち上げる、または押し上げることで対応できる |
| レベル2 | 介助者2人が必要。大きな1段の段差など。車いすを短い距離、完全に持ち上げる必要がある |
| レベル3 | 介助者3人が必要。複数段の階段など。比較的長い距離、車いすを完全に持ち上げ続ける必要がある |
| 不可 | 入口幅が足りず車いすが通れない、エレベーターのない長い階段など、物理的・安全上通行できない |

## 補足

- 分類の中心は、積極的に車いすを持ち上げる介助者の人数。
- ドアは店員に開けてもらえるため、通常は主要な障壁ではない。ただし開口後の有効幅は重要。
- 段差の高さは目安として、約5cmならレベル0または1、約10cmならレベル2相当になり得る。ただし固定ルールではなく、実際の形状・進入角度・車いす・介助方法で変わる。
- 1段か複数段かだけでは判定できない。段差が1段でも大きければ複数人の介助が必要になり得る。
- 入口幅が足りない場合は、段差を越えられるかに関係なく「不可」。
- 一般的な「車いす可」「ベビーカー可」は、個々の利用者のレベルを直接意味しない。
- 大人数がいる特別な状況では通常なら不可の店に一時的に入れる可能性がある。ただし、本人が自分で選ぶ店の通常判定とは分ける。
- AIは最終判断者ではない。利用者本人の実地判断を正解として扱う。

## 外食条件に応じた可否判定

レベルは店舗側の物理的な難易度を表す。実際に今回行けるかは、同行者の総人数ではなく、持ち上げ介助を実行できる人数・条件と照合する。

| 店舗レベル | 目安となる介助者 | 介助者1人での外食 |
|---|---:|---|
| レベル0 | 0人 | 可 |
| レベル1 | 1人 | 可（介助可能な同行者がいる場合） |
| レベル2 | 2人 | 不可 |
| レベル3 | 3人 | 不可 |
| 不可 | 人数に関係なく通行不能等 | 不可 |

ただし、段差の寸法・形状や介助者の対応可否が分からない場合は「要確認」とする。同行者がいることと、その人が車いすを持ち上げられることは同義ではない。
